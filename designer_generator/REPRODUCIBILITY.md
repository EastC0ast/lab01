# Воспроизведение Sprint 2

Нужны Python 3.11 или новее и ASE10.csv в корне репозитория.
Зависимости: `python -m pip install -r designer_generator/requirements.txt`.

```sh
python -m unittest designer_generator.test_generator designer_generator.browser_test -v
python designer_generator/build_sprint2.py
python designer_generator/verify_sprint2.py --execute
python designer_generator/browser_build.py
python -m designer_generator.verify
python designer_generator/browser_verify.py
```

`build_sprint2.py` выполняет самостоятельные исходные ячейки, сохраняет
результаты, CSV, рисунки и две версии ноутбука. Код вычислений самодостаточен:
в ноутбуке присутствуют чтение данных, формулы моделей, оба алгоритма,
численные проверки и построение графиков. При обычном выполнении файлы
не переписываются; режим сохранения включён только в дочернем ядре сборки
через LAB01_SPRINT2_EXPORT=1.

Случайные числа А и GD формируются в отдельных состояниях по seed=40.
Контрольные выборки закона используют seed=20261113. Для 95%-х диапазонов
статистик берутся 600 эталонных выборок; параметры модели при этом фиксированы.
Время семи запусков сравнивается по медиане и квартилям; эти три столбца
могут меняться при повторном выполнении. Остальные численные таблицы должны
воспроизводиться в том же окружении.

`original_generators.py` — историческая версия команды. Рабочие реализации
находятся в `algorithms.py`. В полном GD используются все ступени приёма,
включая экспоненциальную оболочку, и возвращается положительная гамма-величина.
Отражение X=b−θG выполняется в `core.py`. SHA исторического файла записана
в sprint2_verification.json.

Отражённая гамма — учебная аппроксимация. Скошенная нормальная имеет меньший
AIC; её преимущество оставлено в результатах. D после подгонки не используется
как стандартный KS p-value, а временная зависимость сигналов не моделируется.
