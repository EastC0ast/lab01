# Работа с генератором

[Открыть приложение](https://marimo.app/github/EastC0ast/lab01/blob/design-layout/designer_generator/browser_app.py/wasm?embed=true&mode=read&include-code=false&show-code=false)

1. Дождитесь появления полей параметров.
2. Задайте число значений N, начальное число seed, форму a, сдвиг loc и
   масштаб scale, затем нажмите «Сгенерировать».
3. Сравните графики и таблицы двух алгоритмов. Для повторения выборки
   используйте те же параметры и seed.

Начальные параметры оценены по наблюдениям сигнала ASE_NO2. Графики показывают
оценки плотности и эмпирические функции распределения. В таблицах приведены
описательные характеристики, число попыток, доля принятых значений и время
одного запуска.

[Описание модели и особенности GD](README.md#модель).
