# Генерация сигнала NO₂

[Открыть приложение](https://marimo.app/github/EastC0ast/lab01/blob/design-layout/designer_generator/browser_app.py/wasm?embed=true&mode=read&include-code=false&show-code=false)

Дождитесь появления полей. Задайте N, seed, форму a, верхнюю границу b и
масштаб θ, затем нажмите «Сгенерировать». Те же параметры и seed повторяют
выборки. Начальные параметры оценены по ASE_NO2; сигнал измеряется в мкВ.

В модели X=b−θG, G∼Γ(a,1), величина b — правая граница распределения,
а не паспортный предел датчика. Приложение сравнивает алгоритм А и полный GD,
показывает плотности, ECDF, метрики и расстояния как к модели, так и к данным.
Суммы сравниваются только при одинаковом N; начальное N равно 3686.
