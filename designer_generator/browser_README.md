# Браузерная версия генератора

`browser_app.py` — самостоятельная версия того же marimo-приложения для
WebAssembly. Python и библиотеки загружаются в браузере; устанавливать Python,
marimo или редактор на компьютер читателя не требуется.

Публичная ссылка на приложение без редактора кода:

[Открыть генератор в браузере](https://marimo.app/github/EastC0ast/lab01/blob/design-layout/designer_generator/browser_app.py/wasm?embed=true&mode=read&include-code=false&show-code=false).

Работа опубликованного приложения проверена в браузере: менялись N, seed,
форма, сдвиг и масштаб, после нажатия «Сгенерировать» обновлялись таблицы и график.
Результат: [browser_live_verification.json](browser_live_verification.json).
`browser_verification.json` отдельно фиксирует нативные проверки и экспорт.

Данные и алгоритмы включены в один Python-файл. Загрузка локальных модулей,
поиск CSV и обращение к GitHub во время вычислений не нужны. Исходная кодовая
ячейка двух генераторов сохранена посимвольно; вспомогательные функции
представления сохранены посимвольно из `core.py`. Содержательное замечание о GD
сохранено в интерфейсе. Расчёты остаются на Python.

CSV встроен в сжатом виде с SHA256-проверкой. Переводы строк приведены к LF,
как в исходном Git-объекте; содержимое записей и все 3686 значений ASE_NO2
после удаления пропусков сохранены. Отдельный импорт marimo и титульный текст
предшествуют тяжёлым библиотекам, чтобы описание появлялось раньше вычислений.

Для первого открытия нужен интернет и время на загрузку Python, SciPy и
остальных библиотек. Затем форма меняет N, seed и параметры модели и запускает
пересчёт внутри браузера.

`browser_preview.html` содержит только начальные сохранённые результаты.
Рабочая интерактивная ссылка выше запускает `browser_app.py` в браузере.
Дополнительный `browser_wasm.html` для своего статического хостинга можно
собрать командой ниже; в текущую публикацию этот дополнительный файл не включён.

## Воспроизведение подготовки

Для разработчика, из корня репозитория:

```sh
python designer_generator/browser_build.py
python designer_generator/browser_verify.py
```

Для повторной сборки WASM HTML разработчик может использовать
`python designer_generator/browser_verify.py --wasm-export`; только для этого
дополнительного шага нужен инструмент `uv` (его использует экспортёр marimo).
Обычные проверки используют встроенный `unittest` и зависимости приложения.
Сборка восстанавливается из `app.py`, `core.py`, `original_generators.py` и
`ASE10.csv`. Проверки сравнивают точные исходники, CSV, результаты и количество
попыток двух методов для 18 сочетаний параметров. Кроме этого выполняются
проверка marimo и нативное выполнение. Дополнительный шаг формирует настоящий
WASM-экспорт с явными зависимостями PEP 723.
