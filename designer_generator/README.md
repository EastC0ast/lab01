# Генератор команды в marimo

Интерактивное представление двух генераторов сигнала ASE_NO2 из `EastC0ast/lab01`,
ветка `generator`, commit [`01a1c6ce89d076e969bf0a8300fcd9abc2c96e36`](https://github.com/EastC0ast/lab01/blob/01a1c6ce89d076e969bf0a8300fcd9abc2c96e36/lab01.ipynb).
Рабочая ветка — `design-layout`; объединения веток не требуется.

`original_generators.py` содержит посимвольно сохранённую кодовую ячейку 54
с функциями `generate_knuth` и `generate_gd`. Перед ней добавлен импорт NumPy.
Источник и контрольная сумма ячейки находятся в `provenance.json`.
Оценивание параметров сохранено: `scipy.stats.gamma.fit(no2)` со свободным сдвигом.
Обёртка использует тот же `RandomState`, что `np.random.seed`, с отдельным
состоянием для каждого запуска. Числа и количество попыток при одинаковом
seed совпадают с исходной функцией; глобальное состояние NumPy не изменяется.

## Запуск

Из корня репозитория, Python 3.11 или новее:

```sh
python -m pip install -r designer_generator/requirements.txt
python -m marimo run designer_generator/app.py
```

В редакторе: `python -m marimo edit designer_generator/app.py`.
`ASE10.csv` должен находиться в корне репозитория. Число значений, seed,
форма, сдвиг и масштаб меняются в форме и применяются кнопкой
«Сгенерировать». Начальные значения формы, сдвига и масштаба оцениваются по CSV.
Диапазоны представления: целое число значений от 100 до 20 000,
`1 < a <= 1000`, `|loc| <= 10^9`, `10^-6 <= scale <= 10^6`.
Они ограничивают размер расчёта и численные переполнения; сами функции команды
сохранены без правок. Применённые значения проверяются до запуска генераторов.
Выборки, две диаграммы, статистики, число попыток и время обновляются вместе.

Статический снимок `preview.html` показывает начальное состояние. Чтобы менять
параметры и пересчитывать значения, нужен запуск marimo; скачанный HTML
интерактивным вычислительным сервером не является.
Для отображения HTML требуется интернет: интерфейс marimo загружает ресурсы
из своего стандартного CDN.

## Что требует согласования с авторами расчётов

В исходном GD возвращается `loc + scale * (2 * a - x2)`, хотя в математическом
описании задано `loc + scale * x2`. Здесь выражение сохранено, замечание
показано в интерфейсе. Правильность реализации GD и утверждение о его
превосходстве в точности не подтверждены. Таблица диагностики показывает
расстояние D до заданной гамма-модели, асимметрию и число значений ниже `loc`.
Это описание полученной выборки, а не проверка гипотезы с p-value.

Обоснование выбора гамма-модели в источнике не закончено. Асимметричное
распределение не обязательно гамма-распределение. В этой работе КТвД новая
статистическая модель и новые содержательные выводы не вводились.

Единицы ASE_NO2 нужно подтвердить по документации датчика: источник подписывает
их как мкВ. Интерфейс использует «ед. исходных данных», без преобразования
чисел. Это одна величина; исследование двух величин рукописных знаков относится
к отдельному дополнительному заданию.

Время одного запуска не является устойчивой оценкой быстродействия алгоритма.
Исходное измерение `timeit(..., number=100)` не переносилось в реактивный
интерфейс, чтобы изменение параметров не запускало сто повторений.

## Проверки

```sh
python -m designer_generator.verify
```

Или отдельно:

```sh
python -m unittest designer_generator.test_generator -v
python -m marimo check designer_generator/app.py
python -m marimo export html designer_generator/app.py -o designer_generator/preview.html --no-include-code
```

Проверяются сохранность исходной ячейки, точное совпадение чисел и попыток
при трёх значениях формы и трёх seed, повторяемость, независимость от глобального
состояния и отказ от недопустимых параметров. Отчёт о реально выполненных
проверках находится в `verification.json`.
Экспорт дополнительно разбирается: проверяются отсутствие исходного кода
и ошибок в результатах, пять числовых полей, две таблицы, изображение графиков
и подпись применённых начальных параметров. Проверка экспорта не заменяет
визуальный просмотр интерфейса.
