# Генерация сигнала датчика NO₂

[Открыть приложение](https://marimo.app/github/EastC0ast/lab01/blob/design-layout/designer_generator/browser_app.py/wasm?embed=true&mode=read&include-code=false&show-code=false)

Приложение сравнивает алгоритм А и алгоритм GD для гамма-модели сигнала
ASE_NO2. Измените параметры и нажмите «Сгенерировать»: обновятся графики
плотности и эмпирической функции распределения, таблицы характеристик и
показателей работы алгоритмов.

## Параметры

| Поле | Значение |
| --- | --- |
| N | Число генерируемых значений, от 100 до 20 000 |
| seed | Начальное число: одинаковый seed позволяет повторить выборку |
| a | Параметр формы, a > 1 |
| loc (ℓ) | Параметр сдвига |
| scale (θ) | Положительный параметр масштаба |

Начальные параметры оценены по наблюдениям датчика. Единица измерения ASE_NO2
не уточнена, поэтому сигнал показан в единицах исходных данных.

## Модель

Для x > ℓ плотность гамма-распределения имеет вид

```math
f(x)=\frac{1}{\Gamma(a)\theta}
\left(\frac{x-\ell}{\theta}\right)^{a-1}
\exp\!\left(-\frac{x-\ell}{\theta}\right).
```

Гамма-модель рассматривается как приближение. Асимметрия наблюдений сама по
себе не определяет закон распределения. Мера D в таблице показывает
максимальное расстояние между эмпирической функцией распределения и моделью.

## Особенность GD

В реализации GD используется преобразование ℓ + θ(2a − x²), тогда как в
описании метода задано ℓ + θx². Это меняет распределение и может давать
значения ниже ℓ. Для сравнения приведены D, асимметрия и число таких значений.

Выборочные дисперсия и стандартное отклонение рассчитаны с делителем n−1.
Время одного запуска зависит от условий выполнения.
