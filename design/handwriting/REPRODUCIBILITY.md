# Воспроизведение исследования КТвД

Читать работу без установки программ: [полный отчёт](README.md). В [читательском ноутбуке](handwriting.ipynb) и скачиваемом [HTML](handwriting_reading.html) код отсутствует. В HTML встроены все пять изображений; формулы MathJax могут требовать интернет. В [расчётном ноутбуке](handwriting_calculations.ipynb) сохранены исполненные ячейки и результаты.

Для повторного расчёта нужен Python 3.12 и зависимости из корневого `requirements-verified.txt`. Команды выполняются из корня репозитория:

```sh
python -m pip install -r requirements-verified.txt
python design/handwriting/verify_study.py
python design/handwriting/prepare_data.py
python -m unittest discover -s design/handwriting -p test_handwriting.py -v
python design/handwriting/build_study.py
python design/handwriting/verify_study.py
python design/make_reader.py --input lab01_calculations.ipynb
python design/verify_report.py --execute
```

Первой проверкой исследуются сохранённые файлы до пересборки. Исходный архив уже лежит в `data/`, поэтому получение измерений и расчёт не требуют сети. `prepare_data.py` проверяет его SHA-256, строго разбирает записи и заново получает 120 измерений, 60 пар средних и исходные штрихи. Выбор знака зафиксирован в `data/selection_plan.json`; запись метаданных и контрольных сумм — в `data/provenance.json`.

`build_study.py` выполняет анализ, заново исполняет отдельный расчётный ноутбук и сопоставляет результаты. Строятся пять графиков, читательские версии и краткое изложение для общего отчёта. Установлен seed `20261111`; перестановки и bootstrap используют отдельные потоки `SeedSequence`. Число перестановок — 19 999; bootstrap — 10 000. Различия округления в статистических библиотеках могут затрагивать последние знаки; в отчёте сохранена полная точность JSON и CSV.

Автоматические тесты проверяют геометрию, разбор формата, калибровку двух планшетов, полноту отбора, объединение повторений, ранговую статистику, перестановки и парный bootstrap внутри площадок. `verify_study.py` проверяет сохранность данных, исполнение ноутбука, отсутствие кода у читателя, ссылки и побайтовое совпадение пяти графиков с результатами ноутбука и HTML. Итог сборки хранится в [verification.json](verification.json).

Все расчёты этого задания изолированы в `design/handwriting/`. Исходный `lab01_calculations.ipynb` с исследованием сенсоров не изменяется; его сохранность отдельно проверяется относительно исторического коммита. Проверки GitHub Actions выполняются с правами чтения и не записывают файлы в ветки.
