## Проект методики — требует выбора команды

Ниже предложен один возможный способ продолжить работу, **не утверждённый
вариант прежнего исследования**.

Для одного согласованного рукописного знака можно измерять две величины:

\[
X_i = x_{\max,i}-x_{\min,i}\quad\text{— ширина знака, мм},
\]
\[
Y_i = y_{\max,i}-y_{\min,i}\quad\text{— высота знака, мм}.
\]

Границы прямоугольника должны охватывать весь след пишущего инструмента.
Смещение знака на листе в эти величины не входит. Если измерения делаются по
скану, перевод из пикселей в миллиметры выполняется по линейке на том же скане.
Масштаб, разрешение, порог выделения следа и правило обработки отдельных точек
необходимо зафиксировать до обработки всей серии.

Перед сбором данных команда должна выбрать знак, подтвердить эти две величины
или указать другие, определить протокол написания и число наблюдений.
Повторения одного человека нельзя автоматически считать независимыми
наблюдениями: состав участников и порядок повторений сохраняются отдельно.

## Форма сбора данных

[measurements_template.csv](measurements_template.csv) содержит только заголовок,
без выдуманных строк. Поля `width_mm` и `height_mm` относятся к предложенной
методике; остальные поля — идентификаторы и условия измерения.

| Поле | Содержание |
| --- | --- |
| `sample_id` | Уникальный идентификатор написанного экземпляра |
| `sign` | Согласованный знак |
| `writer_id` | Условный код участника |
| `repetition` | Номер повторения участника |
| `width_mm` | Ширина, мм, положительное число |
| `height_mm` | Высота, мм, положительное число |
| `source_id` | Идентификатор листа или исходного изображения |
| `measurement_method` | Линейка или описание обработки скана |
| `notes` | Условия, пропуски, повреждения и спорные измерения |

При заполнении CSV десятичный разделитель — точка, разделитель полей — запятая;
текст с запятой заключается в двойные кавычки. Пропуски не заменяются нулями.

## Анализ после получения данных

1. Проверить идентификаторы, пропуски, единицы и положительность обеих величин;
   спорные строки сохранить с объяснением решения.
2. Для ширины и высоты отдельно привести объём выборки, среднее, медиану,
   стандартное отклонение и квартильный размах. Построить гистограммы и
   эмпирические функции распределения с подписями осей в миллиметрах.
3. Показать парную диаграмму ширины и высоты; учитывать повторения участников
   при оценке связи. Не трактовать корреляцию как причинность.
4. Подбирать модель распределения по реальным данным, не предполагать
   нормальность заранее. Метод проверки, уровень значимости и ограничения
   описать рядом с результатами.

До появления исходных данных этот раздел остаётся методикой и формой сбора;
он не подтверждает выполнение дополнительного экспериментального задания.
